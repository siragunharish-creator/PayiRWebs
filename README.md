# PayirWebs

React + TypeScript + Vite + Tailwind CSS landing page.

## Run locally
```
npm install
npm run dev
```

## Build
```
npm run build
```

## Deploy on Vercel
Import the GitHub repo. Vercel auto-detects Vite:
- Build command: `npm run build`
- Output directory: `dist`

Before launch, replace the placeholder WhatsApp number `919876543210` in `src/App.tsx`.
